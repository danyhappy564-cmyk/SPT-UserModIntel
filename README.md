# SPT-UserModIntel

SPT(Single Player Tarkov)용 **다른 사람이 만든 모드**를 직접 풀어 보고 정리한 분석문 모음입니다.
모드가 실제로 무엇을 하는지, 장점과 단점, 다른 모드와 같이 써도 되는지를 일반 사용자도 읽을 수 있게 씁니다.

- 분석은 모드 DLL을 디컴파일해서 코드와 설정 설명을 직접 확인한 결과입니다.
- FPS 같은 수치는 따로 측정했다고 적힌 경우에만 측정한 값입니다.
- 각 보고서는 한국어·영어 전환 버튼이 있는 웹페이지입니다.
